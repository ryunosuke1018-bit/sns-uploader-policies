Privacy Policy

SNS Uploader — Privacy Policy

Effective date: September 16, 2026

SNS Uploader is a personal, single-user tool that runs on its developer's own computer. It is not a hosted service: there is no server operated by this tool that stores or processes anyone's data. This page explains what information the tool touches, and where it lives.

01 Who this applies to

This tool is used only by its developer, on accounts the developer owns. It is not distributed to, or used by, the general public, so this policy describes handling of the developer's own account data — not third-party user data.

02 What the tool accesses

To publish a video, the tool requests the minimum API access each platform requires for content upload:

PlatformAccess used
YouTubeOAuth token scoped to youtube.upload — upload videos to the developer's own channel
InstagramInstagram Login access token and Instagram Business Account ID — publish media to the developer's own professional account
TikTokContent Posting API client key/secret and access token — upload videos to the developer's own TikTok account
XAPI key/secret and access token — post media to the developer's own account

03 Where credentials and tokens are stored

All API keys, client secrets, and access/refresh tokens are stored in local files on the developer's own computer, inside a private credentials folder. They are never transmitted to any server other than the official API endpoints of YouTube, Instagram, TikTok, and X themselves.

04 What is not collected

  • No analytics, tracking, or telemetry is collected by this tool.
  • No data about viewers, followers, or other platform users is collected or stored.
  • No data is sold, rented, or shared with any third party.

05 Video content

Video files processed by the tool remain on the developer's own device before and after upload. The tool does not copy them to any external storage beyond the destination platform the operator chooses to publish to.

06 Data retention and deletion

Locally stored tokens remain until the developer deletes the credentials files or revokes access from within each platform's own account settings (e.g., YouTube's "Third-party apps with account access," Instagram's "Apps and Websites," TikTok's connected-apps settings, or X's connected-apps settings).

07 Children's privacy

This tool is not directed at children and is not used to process data belonging to children.

08 Changes to this policy

This policy may be updated as the tool evolves. The effective date at the top of this page reflects the most recent revision.
